# Seeed phone/display relay

This sketch preserves the working local instrument firmware and adds a framed
USB display-command parser plus an ESP-NOW request/acknowledgement channel.
Use it on the Seeed XIAO ESP32-S3, not on the BOX-3.

See [the display setup instructions](../23_phone_display/README.md) for wiring,
both firmware builds, protocol, phone APK and mock/emulator testing.
